# (A.4) Digital Musicology : Course Materials

This repository contains the slides and practical notebooks for the course Digital Musicology at University of Music and Performing Arts Graz. 

The course introduces computational approaches to studying music, combining musicological research questions with data analysis and programming in Python.

## Content

### Lectures
- What does digital musicology do?
- Computational analysis of musical scores
- Operationalization and statistical analysis - Part 1
- Operationalization and statistical analysis - Part 2
- Audio Processing 
- MIR Tools for music processing and musicology 

### Practice

- 1: Vibe coding for musicologists in music21
- 2: Symbolic music processing continued
- 3: Symbolic music processing and statistical analysis
- 4: Sonic Visualizer
- 5: Exploring harmony in pop music
